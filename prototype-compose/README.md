# Professor OS Desktop

The Kotlin Compose workspace uses Java academic services and Supabase-backed storage. The default launcher requires a provisioned professor account and TOTP MFA. The separate SQLite recovery workspace remains available through the Gradle runRecovery task or the installed executable's --recovery argument.
